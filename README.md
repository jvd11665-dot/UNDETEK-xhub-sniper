[-- Autofarm v2.4 — modes + case vide --]
1. Join Sniper Duels **lobby**
2. Exec `autofarm.lua` **ONCE** (Xeno)
3. Popup **MRN / UNDETEK** → choisis **1v1 / 2v2 / 3v3 / 4v4**
4. Prefère une **case vide** (aucun joueur ~10 studs) parmi les 4 pads du mode
5. Suit le PATH (MoveTo + sprint) jusqu'à la case
6. Si **>250 studs** du lobby → charge combat Rage
7. **Combat OFF** au lobby
8. Fin de match → souris sur **RETURN TO LOBBY** → re-scan case vide → re-path
9. Stop: leave / quit Xeno / unload autofarm
