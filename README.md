2. Exec `autofarm.lua` **ONCE** (Xeno)
3. Suit le PATH enregistré jusqu'à la case **1v1** (plus de clic PLAY)
4. Si **>250 studs** du lobby → charge combat Rage
5. **Combat OFF** au lobby
6. Fin de match → souris sur **RETURN TO LOBBY** → re-path
7. Stop: leave / quit Xeno / unload autofarm
